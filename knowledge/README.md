# knowledge/

RAG（モジュール 2-1）で検索の対象にする、あなた自身の文書を置く場所です。

## 置き方

- 文書をこのディレクトリの直下に置きます。サブディレクトリは走査しません。
- このファイル（`README.md`）以外の中身は Git の追跡対象外です（`.gitignore` の `knowledge/*`）。個人の文書や社内文書をコミットする心配はありません。

## 対応形式

| 形式 | 拡張子 | 扱い |
|---|---|---|
| Markdown | `.md`、`.markdown` | ATX 見出し（`#`〜`######`）の階層を保って分割します。コードフェンスの中は見出しとして扱いません |
| PDF | `.pdf` | ページ単位でテキストを取り出して分割します。スキャン画像だけの PDF（テキスト層がないもの）は OCR しないため、「テキストなし」として取り込みをスキップします |

## 制限

- 1 回の取り込みで扱えるファイルは最大 50 件、1 ファイルあたり最大 5 MiB です。
- 取り込み対象は、このディレクトリ内の**ファイル名**で指定します。ブラウザからのアップロードは扱いません。
