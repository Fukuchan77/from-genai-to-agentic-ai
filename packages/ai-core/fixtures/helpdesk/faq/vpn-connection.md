# VPN 接続手順

社外から社内システムを使うときは、VPN に接続します。このページは、VPN クライアントの設定と、接続できないときの確認手順をまとめたものです。

## 初回の設定

VPN クライアントは、ソフトウェアポータルの「ネットワーク」カテゴリから入手します。インストール後に「新しい接続」を選び、接続先に社内で案内されているゲートウェイ名を入力します。認証方式は「社員アカウント＋認証アプリ」を選びます。

## 接続できないとき

次の順に確認してください。

1. 社外のネットワークに接続できているか（ブラウザーで外部の Web サイトを開けるか）を確認する。
2. 認証アプリの時刻表示が正しいか確認する。端末の時刻がずれていると、ワンタイムコードが拒否される。
3. VPN クライアントを最新版に更新する。古い版では接続を拒否される場合がある。
4. 上記で解決しないときは、クライアントの「接続ログを保存」を実行し、ヘルプデスクにログを添付して連絡する。

## 接続が頻繁に切れるとき

ホテルや共用のネットワークでは、一定時間通信がないと接続が切れることがあります。クライアントの設定で「接続を維持する」を有効にしてください。それでも切れる場合は、モバイル回線への切り替えを試してください。
