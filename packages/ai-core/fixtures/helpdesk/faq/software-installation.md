# ソフトウェアのインストール

業務で必要なソフトウェアを、パソコンに導入する手順です。

## ソフトウェアポータルを使う

会社が許可したソフトウェアは、ソフトウェアポータルから自分でインストールできます。一覧にあるものは、管理者の承認なしに導入できます。

## 一覧にないソフトウェア

一覧にないソフトウェアを使いたいときは、ポータルの「導入申請」から申請します。申請には、利用目的、利用する期間、ライセンスの有無を記入してください。情報システム部門が確認し、通常 3 営業日以内に結果を連絡します。

## 個人で入手したソフトウェア

インターネットで入手したソフトウェアを、申請なしで導入することは禁止されています。セキュリティ上の理由で、自動的に削除される場合があります。
