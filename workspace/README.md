# workspace/

ファイル操作ツールと自作の MCP ファイルサーバー（モジュール 3-1）が触れてよい、**唯一の許可ルート**です。エージェントはこのディレクトリの内側のファイルだけを一覧・読み取り・検索できます。

## 置き方

- 読ませたいファイルをこのディレクトリに置きます。サブディレクトリも使えます。
- このファイル（`README.md`）以外の中身は Git の追跡対象外です（`.gitignore` の `workspace/*`）。個人のファイルをコミットする心配はありません。
- 許可ルートを変えるときは、環境変数 `MCP_FS_ROOT` に別のディレクトリを指定します（既定は `workspace/`）。起動時に実パス（シンボリックリンクを解決した絶対パス）へ解決され、存在しなければサーバーは作らずに終了します。

## 置いてよいファイル

- テキストファイル（Markdown、CSV、ログ、ソースコードなど）。
- 秘密情報（API キー、トークン、個人情報）は置かないでください。ツールが読み取った内容はモデルの入力になります。

## パスの制約

- ツールには**許可ルートの内側の絶対パス**を渡します。相対パスは拒否され、修正ガイドが返ります（回復可能）。
- `..` やシンボリックリンクで許可ルートの外へ出るパスは、実パスに解決した結果で判定されて拒否されます。この拒否は**致命的**で、実行は停止理由 `error` で止まり、許可ルートのパスを含むメッセージが表示されます。
- ルートと同じ接頭辞を持つ別のディレクトリ（`workspace-evil/` など）は、許可ルートの配下とは見なされません。判定はパス区切り単位です。

## 書き込み・削除について

`writeFile` と `deleteFile` は自作サーバーが公開しますが、承認ゲート（M4）が実装されるまで、エージェントには**登録されません**。M3 のハンズオンは読み取りだけで完結します。
